# Morocco Responsible Travel Advisor

A web application that helps you find eco-friendly travel options within Morocco, balancing your budget, time, and environmental impact.

## Features

- **Priority-Based Recommendations**: Adjust sliders for ecological impact, budget savings, and travel duration
- **Comprehensive Moroccan Routes**: 50+ realistic routes across 10 cities (trains, buses, flights)
- **Detailed Metrics**: View CO2 emissions, costs, durations, and scores for each option
- **Group Travel Support**: Calculate costs for up to 10 travelers
- **Beautiful UI**: Modern, responsive design with smooth animations

 
## Usage

1. Click "Planifier mon voyage" on the home page
2. Select your origin and destination cities
3. Set your budget and number of travelers
4. Adjust the priority sliders to match your preferences:
   - **Impact écologique**: Prioritize low CO2 emissions
   - **Économies budgétaires**: Prioritize lower costs
   - **Durée du trajet**: Prioritize shorter travel times
5. Click "Trouver mes options" to see recommendations

## Technology Stack

- **Backend**: FastAPI + Python
- **Logic Engine**: Python (with Prolog support)
- **Frontend**: React (CDN) + TailwindCSS
- **Data**: Realistic Moroccan transport network
